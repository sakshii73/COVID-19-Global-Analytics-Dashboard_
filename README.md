# COVID-19 Global Analytics Dashboard | Tableau

## Project Overview

The COVID-19 Global Analytics Dashboard is a data visualization project created using Tableau to present and explore global COVID-19 statistics. The dashboard organizes key metrics and visual comparisons into a single view, helping users understand differences in reported cases across countries and continents.

The dashboard includes KPI cards, interactive filters, bar charts, a death-rate visualization, and a geographic map.

## Dashboard Preview

![COVID-19 Global Analytics Dashboard](covid-19-global-dashboard.png)

## Project Objectives

- Present important COVID-19 statistics in a clear visual format.
- Compare reported cases across countries and continents.
- Explore active cases, recovered cases, and death-rate metrics.
- Visualize geographic differences using a filled map.
- Make data exploration easier through dashboard filters and charts.

## Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard displays the following high-level metrics:

- **Total Cases:** Reported COVID-19 cases.
- **Total Deaths:** Reported deaths associated with COVID-19.
- **Total Recovered:** Reported recoveries.
- **Active Cases:** Active cases as represented in the source data.
- **Population:** Population figures included in the dataset.

### 2. Cases by Continent

A bar chart compares reported COVID-19 cases across continents, helping users explore differences between geographic regions.

### 3. Top 10 Countries by Cases

A country-level comparison highlights the countries with the highest reported case totals in the displayed data.

### 4. Active vs. Recovered Cases

A bar chart compares active and recovered case values to help users examine differences between these metrics.

### 5. Death-Rate Analysis

A chart presents death-rate values across selected locations, supporting comparisons of the metric represented in the dataset.

### 6. Geographic Analysis

A filled map displays COVID-19 case totals geographically, helping users explore the distribution of reported cases across locations.

### 7. Interactive Filters

Country and continent filters allow users to narrow the displayed information to selected locations.

### 8. Additional Dashboard Views

The workbook screenshot includes additional views such as Daily New Cases and Daily New Death.

## Tools and Technologies

- **Tableau:** Dashboard development and data visualization.
- **Data Visualization:** KPI cards, bar charts, and geographic mapping.
- **Data Analysis:** Comparison and exploration of country-level and continent-level statistics.

## Key Analytical Questions

This dashboard can help explore questions such as:

- Which countries have the highest reported case totals in the dataset?
- How do reported case totals differ across continents?
- How do active and recovered case values compare?
- How does the displayed death-rate metric vary across locations?
- What geographic patterns are visible in the reported case totals?

## Project Outcomes

- Organized multiple COVID-19 indicators into a single dashboard view.
- Presented country-level and continent-level comparisons visually.
- Combined KPI cards, charts, filters, and geographic visualization.
- Created a visual reporting interface for exploring global COVID-19 statistics.
